Whatsapp is a Java-based console application designed as an integrated messaging and user authentication system. Developed within the NetBeans IDE, the system enforces strict security and data validation standards across three core modules: PROG POE.pdf
1. Part 1 (User Management): Handles secure user registration and login by validating usernames against specific format constraints, enforcing robust password complexity rules, and validating South African cell phone numbers via regular expressions. PROG POE.pdf
2. Part 2 (Messaging & Storage): Implements automated message tracking, unique 10-digit ID generation, custom string-manipulated Message Hashes (e.g., 00:0KS), and JSON file storage handling for messages. PROG POE.pdf
3. Part 3 (Data Structures & Reporting): Utilizes parallel arrays to manage, search, sort, and delete sent, stored, and disregarded messages, while providing detailed reporting features. PROG:HITHAN POE.pdf
The project emphasizes software engineering best practices, incorporating unit testing via JUnit, version control via Git/GitHub, and continuous integration through GitHub Actions.
